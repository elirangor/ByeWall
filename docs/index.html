Page Rewind 📰

How to use on Android

1
Tap the ⋮ three-dot menu in your browser
2
Tap Add to Home Screen → then tap Install on the prompt
3
Browse to any page you want to view archived
4
Tap Share → choose Page Rewind
5
The archived version opens instantly

📱 On iPhone / Safari

1
Install the Shortcuts below via the Shortcuts app
2
In Safari tap Share → choose your Page Rewind shortcut
🗄️ Install Archive.today Shortcut 🌐 Install Wayback Machine Shortcut
